# Навагодняя ёлка · New Year Countdown Tree

An ASCII-rendered 3D voxel Christmas tree with a golden clock dial on the ground and a live countdown to the New Year. All on-page text is in Belarusian.

- Built with Three.js (loaded from a CDN) plus a custom ASCII post-processing shader
- Intro animation: the dial draws in, the tree grows from the bottom up, the star appears, the lights switch on, presents drop in, and a light-outline reindeer is traced
- The dial's hands show your local time, and the countdown runs to January 1. On New Year's Day it shows "З Новым годам!" with fireworks
- Drag to orbit, scroll or pinch to zoom, and tap a present

Open `index.html` in a browser, or view it on GitHub Pages.
